# OpenRouter Models - Raycast Extension

Browse and search AI models available on OpenRouter directly from Raycast. This extension provides a convenient way to explore model capabilities, pricing, and technical details.

## Features

- 🔍 Search through available AI models
- 📊 View detailed model information including pricing and context lengths
- 📋 Quick copy model IDs for use in your applications
- 📚 Easy access to model documentation
- 🏢 Models organized by provider
- 💰 Clear pricing information for both prompt and completion tokens

## Installation

1. Make sure you have [Raycast](https://raycast.com/) installed
2. Install the extension from the Raycast store
3. Get your OpenRouter API key from [OpenRouter](https://openrouter.ai/keys)
4. Add your API key in the extension preferences

## Usage

1. Open Raycast (default: ⌘+Space)
2. Type "OpenRouter Models" or "orm"
3. Press enter to see the list of available models
4. Use the search bar to filter models
5. Select a model to:
   - View detailed information
   - Copy the model ID
   - Open documentation in browser

## Development

This extension is built with:
- TypeScript
- React
- Raycast API
- OpenRouter API

To develop locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/raycast-openrouter

# Install dependencies
bun install

# Start development server
bun run dev
```
